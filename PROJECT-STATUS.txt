================================================================================
                          SUPPORTED WORKFLOWS
================================================================================

1. CREATE NEW NOTEBOOK
   M-x wolfram-nb-create-new → Edit → C-x C-s

2. OPEN EXISTING NOTEBOOK
   M-x wolfram-nb-open → Edit → C-x C-s

3. EDIT IN EMACS, EXECUTE IN MATHEMATICA
   Edit in Emacs → Save → Open in Mathematica → Execute

4. VERSION CONTROL
   Edit → Save → Git commit → Track changes

================================================================================
                            KNOWN LIMITATIONS
================================================================================

By Design:
  - No rendering of Dynamic content (Dynamic[], Manipulate[])
  - No graphics display (Emacs limitation)
  - Complex cell metadata not preserved
  - Rich text formatting limited
  - Best for static documents

These limitations are intentional - the mode focuses on document structure
and content editing, not interactive execution or graphics.
