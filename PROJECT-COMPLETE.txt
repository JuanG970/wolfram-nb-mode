📦 WHAT IS IT?

An Emacs major mode that allows you to edit Wolfram Language Notebook (.nb) 
files using org-mode syntax. It provides seamless bidirectional conversion 
between Cell[...] structures and familiar org-mode elements.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ KEY FEATURES

  ✓ Parse .nb files into org-mode representation
  ✓ Edit using familiar org-mode interface
  ✓ Save back to proper Notebook format
  ✓ Support for Sections, Text, Code, Lists
  ✓ Proper string escaping/unescaping
  ✓ Interactive commands and key bindings
  ✓ Works with Mathematica and Wolfram Desktop

🚀 GETTING STARTED

1. Add to your ~/.emacs:
   (add-to-list 'load-path "/path/to/wolfram-nb-mode")
   (require 'wolfram-nb-mode)

2. Open a notebook:
   M-x wolfram-nb-open RET notebook.nb RET

3. Edit using org-mode syntax

4. Save with C-x C-s

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 EXAMPLE

Org-mode:                          Wolfram Notebook:
────────────────────────          ────────────────────────
* My Notebook                     Notebook[{
                                  Cell["My Notebook", "Section"],
Some text here.                   Cell["Some text here.", "Text"],
                                  Cell["Code Example", "Subsection"],
** Code Example                   Cell["Plot[Sin[x], {x, 0, 2Pi}]", "Code"]
                                  }]
#+begin_src wolfram
Plot[Sin[x], {x, 0, 2Pi}]
#+end_src
